Om sajten

Vladimirs Spelsajt är ett hobbyprojekt. Alla spel körs helt i din webbläsare – ingen installation, inga konton och inget som sparas någon annanstans än lokalt hos dig.

Sidan är byggd med ren HTML, CSS och JavaScript och ligger på GitHub Pages. Har du ett spelförslag? Öppna gärna ett issue i repot.
